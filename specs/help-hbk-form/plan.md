# help-hbk-form: план реализации и решения

Транзиентный спутник [`spec.md`](spec.md).

## 1. План реализации

### Этап 1. Разметка формы (`Form.xml`)

- Группа `ГруппаНастроекСправка` внутри существующей `Настройки` (рядом с `ГруппаНастроек1..3`).
- Реквизиты формы (свободные id ≥ 27): `ФайлСправки1С` (строка, `<Save>`),
  `ЗагружатьСправкуПриОткрытии` (булево, `<Save>`), `СостояниеСправки` (строка).
- Элементы (свободные id ≥ 93): `InputField ФайлСправки1С` (`ChoiceButton`, событие `StartChoice`),
  `CheckBoxField ЗагружатьСправкуПриОткрытии`, `Button ЗагрузитьСправку`,
  `LabelDecoration СостояниеСправкиНадпись`.
- Команда `ЗагрузитьСправку` (свободный id ≥ 31).
- Gate: `load_form.ps1` собирает epf без ошибок (exit 0) — форма валидна.

### Этап 2. Код формы (`Module.bsl`, область `СправкаHBK`)

- `НайтиФайлСправки()` — `КаталогПрограммы()` → соседние каталоги версий (сортировка по убыванию).
- `ФайлСправки1СНачалоВыбора` — `ДиалогВыбораФайла(Открытие)`, фильтр `*.hbk`.
- Конечный автомат передачи на `ПодключитьОбработчикОжидания`: очередь пакетов
  (`shlang` → `shcntx`), в каждом — чтение порций `ЧтениеДанных` → `Base64Строка` →
  `pushBase64Chunk`, затем `endBase64Transfer` + `parseHelp`.
- Индикация в `Элементы.СостояниеСправкиНадпись.Заголовок`.
- Врезки: `ПриСозданииНаСервере` (восстановление настроек), `ИнициализацияРедактора` (автостарт).
- Gate: сборка epf + ручной прогон в поле владельцем.

Код области хранится в репозитории копией — [`form_module_fragment.bsl`](form_module_fragment.bsl)
(в самой обработке он живёт внутри `.epf`, вне контроля версий).

### Этап 3. Полевой гейт

- Сборка `bsl_console_test\console-055-справка.epf` (не трогая `Рабочие\`).
- Владелец проверяет: автоподстановка пути, прогресс, `CTRL+F1`, сохранение настроек.
- После подтверждения — промоушен в `Рабочие\console-monaco-0.55.epf` и, при желании, порт на 0.20.

### Риски и снижение

- **40 МБ через мост.** Порции по 1 МБ, пачками по таймеру; при провале — уменьшить порцию/пачку.
- **Отзывчивость формы.** Читаем и отдаём порции только в обработчике ожидания, не в цикле.
- **`Base64Строка` вставляет переводы строк.** По контракту моста пробельные символы игнорируются.
- **Разная разрядность/версии платформы.** Поиск не привязан к конкретной версии: берём
  `КаталогПрограммы()`, затем перебираем каталоги установки.

## 2. Открытые вопросы

- Нужен ли флажок автозагрузки (сделан включённым по умолчанию) или грузить всегда — решает владелец
  по итогам полевого прогона.
- Стоит ли предложить автору PR с примером загрузки HBK из 1С в `docs/help_browser.md`.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-08-12 | Работаем только в обёртке-epf, `src/` не трогаем | Функциональность редактора уже есть в 0.5.3, нужен вызывающий код |
| 2026-08-12 | Настройки — реквизиты формы с `<Save>` (автосохранение данных формы) | У формы уже `AutoSaveDataInSettings = Use`, как у `ОтображатьПробелыИТабуляции`; восстановление происходит до `ПриОткрытии`, где работает автопоиск |
| 2026-08-12 | Грузим оба пакета (`shlang` + `shcntx`) | `shlang` крошечный, даёт справку по встроенному языку бесплатно |
| 2026-08-12 | Порция 1 МБ, пачка 4 порции за такт таймера | Компромисс скорости и отзывчивости формы; 40 МБ ≈ 10 тактов |
