# help-hbk-form: загрузка синтакс-помощника 1С из формы консоли

> Связано: [`docs/help_browser.md`](../../docs/help_browser.md),
> [`docs/base64_transfer.md`](../../docs/base64_transfer.md), спека автора
> [`specs/help-browser/spec.md`](../help-browser/spec.md).

Стабильный контракт: что должно быть реализовано и как пользователь консоли это видит.

## 1. Контекст и проблема

В релизе **0.5.3** редактор получил встроенный браузер синтакс-помощника: панель справа, `CTRL+F1`
по слову под курсором, поиск и содержание. Но сам пакет справки (`shcntx_*.hbk` — объектная модель,
`shlang_*.hbk` — встроенный язык) редактор **не добывает сам**: файлы должен передать вызывающий код
через `parseHelp()` либо через порционный Base64-мост (`beginBase64Transfer` / `pushBase64Chunk` /
`endBase64Transfer`).

**Что уже есть у автора.** В `console.epf` из релиза v0.5.3 есть демонстрационная реализация:
кнопка меню «Загрузить синтаксис-помощник» → `ПолучитьФайлСправки("shcntx_ru.hbk")`
(`НайтиФайлы(КаталогПрограммы(), …)`) → `ЗагрузитьФайлВРедактор` (`ФайловыйПоток` +
`БуферДвоичныхДанных` по 1 МБ + `ПолучитьBase64СтрокуИзБуфераДвоичныхДанных` со срезкой `ПС`/`ВК`) →
`parseHelp()` + `showHelp()`; на `EVENT_ON_HELP_READY` — `ПоказатьПредупреждение`. Это образец
вызова API: имя файла зашито, цикл синхронный (форма стоит на время передачи ~40 МБ), настроек,
автозапуска, прогресса и пакета встроенного языка нет.

В рабочей обработке `КонсольКода.epf` этого кода нет вовсе, поэтому `CTRL+F1` в поле 1С молчит:
справка не загружена. Файлы при этом всегда лежат рядом — в каталоге установленной платформы
(`КаталогПрограммы()`), например `C:\Program Files\1cv8\8.3.27.2214\bin\shcntx_ru.hbk` (≈40 МБ) и
`shlang_ru.hbk` (≈90 КБ). Задача — научить форму находить их и грузить, не заставляя пользователя
искать путь вручную.

## 2. Область изменений

Изменяется **только обёртка-обработка** (форма `КонсольКода`), код редактора (`src/`) не трогаем.

| Компонент | Тип | Характер изменений |
| --- | --- | --- |
| `Forms/Форма/Ext/Form.xml` | форма .epf | группа настроек «Синтаксис-помощник»: поле пути, флажок автозагрузки, кнопка, надпись состояния; 2 реквизита формы; команда `ЗагрузитьСинтаксисПомощник` |
| `Forms/Форма/Ext/Form/Module.bsl` | форма .epf | область `СинтаксисПомощник` (имя и helper `ПолучитьФайлСправки` — как у автора): поиск файла, диалог выбора, порционная передача, индикация состояния; врезки в `ПриСозданииНаСервере`, `ПриОткрытии`, `ИнициализацияРедактора`, `ОбработатьСобытиеРедактора` |
| `specs/help-hbk-form/` | доки | эта спека + план |

## 3. Поведение

### 3.1. Основной сценарий

1. Путь к `shcntx` и признак автозагрузки — реквизиты формы с автосохранением
   (`<Save>` при `AutoSaveDataInSettings = Use`), поэтому платформа сама восстанавливает их при
   открытии; при первом запуске путь пуст, автозагрузка включена.
2. Если путь пуст — форма ищет файл сама: `КаталогПрограммы()`, затем — соседние каталоги версий
   платформы (самая свежая версия первой). Ищется русский пакет `shcntx_ru.hbk`; найденный путь
   подставляется в настройку и сохраняется.
3. После готовности редактора (`ConsoleOnReady` → `ИнициализацияРедактора`), если автозагрузка
   включена и путь заполнен, запускается поэтапная передача:
   `shlang_*.hbk` (маленький, одним куском) → `parseHelp()`, затем `shcntx_*.hbk` порциями по 1 МБ →
   `parseHelp()`. Порции уходят пачками по таймеру, чтобы форма оставалась отзывчивой.
4. Ход выполнения виден в надписи группы настроек: `Справка 1С: shcntx_ru.hbk — 42%` → по завершении
   `Справка 1С: загружена (объектная модель + встроенный язык)`.
5. После загрузки `CTRL+F1` в редакторе открывает панель справки на статье по слову под курсором.

Настройки «Справка 1С» живут в панели настроек формы (кнопка-шестерёнка в командной панели):
поле пути с кнопкой выбора файла, флажок «Загружать при открытии», кнопка «Загрузить справку»
(ручной запуск в любой момент) и надпись состояния.

### 3.2. Граничные случаи

- **Файл не найден** — путь остаётся пустым, состояние: `Справка 1С: файл shcntx_*.hbk не найден`,
  загрузка не запускается; пользователь может указать путь вручную.
- **`shlang` рядом отсутствует** — грузится только объектная модель, это не ошибка.
- **Ручной выбор** — диалог открывается в каталоге текущего значения, фильтр `*.hbk`; можно выбрать
  как `shcntx_*.hbk`, так и файл другой локализации (`_root`), парой к нему подбирается `shlang_*`
  из того же каталога с тем же суффиксом.
- **Повторный запуск** во время идущей загрузки — игнорируется (защита от двойного клика).
- **Веб-клиент** — раздел справки недоступен (нет файлового доступа), как и остальная функциональность
  консоли в вебе.
- Автозагрузку можно выключить флажком: тогда справка грузится только по кнопке.

### 3.3. Ошибки

- Ошибка чтения файла или исключение моста прерывает передачу, состояние показывает текст ошибки,
  ранее загруженный пакет в редакторе остаётся живым (гарантия `parseHelp`).
- Ошибочный/повреждённый пакет: `parseHelp` вернёт `{ok: false, error}` — текст ошибки выводится в
  состояние.

## 4. Контракты

### 4.1. Экспортные функции моста (используются, не меняются)

```js
window.beginBase64Transfer(name);   // начать передачу
window.pushBase64Chunk(chunk);      // очередная порция Base64
window.endBase64Transfer();         // завершить, опубликовать Blob
window.parseHelp();                 // разобрать последний Blob (Promise)
window.showHelp();                  // открыть панель (не используется формой)
```

Изменений в публичном контракте редактора **нет** — форма только вызывает существующее API 0.5.3.

### 4.2. События

Форма не подписывается на `EVENT_ON_HELP_READY` и не включает `generateGetHelpEvent`: состояние
загрузки форма знает и без событий, а `CTRL+F1` обрабатывается редактором самостоятельно.

### 4.3. Контракт сборки / доставки

HTML-бандл не меняется. Меняется только `.epf`: пересборка через `tools/make_epf.ps1`
(дамп формы → правка `Form.xml` + `Module.bsl` → load). Проверочные сборки кладутся рядом с
рабочими, **рабочие файлы не перезаписываются** до подтверждения в поле.

## 5. Критерии приёмки

- [ ] В панели настроек есть раздел «Справка 1С»: путь + кнопка выбора, флажок, кнопка загрузки,
      состояние.
- [ ] При первом открытии на машине с установленной платформой путь подставляется автоматически.
- [ ] Загрузка стартует сама и не «вешает» форму: интерфейс отзывчив, прогресс растёт.
- [ ] После завершения `CTRL+F1` над словом (например, `ТаблицаЗначений`) открывает панель со статьёй.
- [ ] Путь и флажок переживают закрытие/открытие формы.
- [ ] При отключённом флажке автозагрузки на открытии ничего не грузится, кнопка работает.
- [ ] Несуществующий путь даёт понятное состояние, а не срыв формы.

## 6. Вне области

- Изменения в `src/` (код редактора) — не трогаем.
- Загрузка `shquery_*.hbk` (справка языка запросов) — редактор такие пакеты не разбирает.
- Автоматическое обновление справки при смене версии платформы.
- Кеширование распакованного пакета между сеансами (редактор держит его только в памяти страницы).
- Порт настройки в ветку `webpack_0_20` (сделаем тем же приёмом, если понадобится).
